ℹ️ 关于 StatsViz Pro

StatsViz Pro v1.0.0

专业的跨平台数据统计与可视化分析平台

支持平台：

  • ✅ Windows 10/11 (NSIS 安装包 + 便携版)
  • ✅ macOS 10.15+ (DMG 安装包)
  • ✅ Linux (deb + AppImage)
  • ✅ 任何现代浏览器 (Chrome/Firefox/Edge/Safari)
  • ✅ 移动端浏览器响应式适配

功能特性：

  • ✅ 数据本地处理，隐私安全
  • ✅ 支持 8 种常用统计图表
  • ✅ 自动计算 12 项描述统计指标
  • ✅ 一键生成 Python 分析代码
  • ✅ 图表一键导出高清 PNG

技术栈：Electron + HTML/CSS/JavaScript + ECharts
